🧬 The Evolution of Lebirun

Every great technological project has an origin story.

Lebirun's development represents an ongoing journey through different programming languages, technologies, and architectural approaches.

🏁 Generation 01 — The Beginning

The original Lebirun was developed using C# and Cosmos.

This initial generation established the foundation of the project and introduced the idea of building an independent operating system environment.

⚙️ Generation 02 — Lebirun C

The next evolution brought the project into the world of C programming.

This transition represented a move toward lower-level development and a deeper exploration of operating system engineering.

🚀 Generation 03 — The New Lebirun

The current generation continues the journey.

With a renewed development direction and an evolving architecture, Lebirun explores the possibilities of building a standalone hobby operating system.

🌠 Generation ∞ — Beyond the Horizon

🛸 Engineering the Digital Universe

Behind every futuristic vision lies real engineering.

Lebirun is built around the exploration of fundamental operating system concepts and low-level software development.

Its repository contains components covering different parts of the system:

Component	Purpose
🧠 Kernel	Core operating system development
📦 Initrd	Initial RAM disk
🔧 LibC	C library components
🧩 Modules	Modular system components
🖥️ User Programs	User-space applications
🎛️ Lebconfig	Configuration system
📟 Terminfo	Terminal information
🛠️ Build Scripts	Build and development automation

The project uses a GNU/Linux-based development environment and supports experimentation through QEMU.

⚡ Getting Started

Ready to enter the Lebirun universe?

Let's prepare your development environment.

🧰 Requirements

On Debian-based distributions:

bash
sudo apt update

sudo apt install \
    build-essential \
    grub-common \
    grub-pc-bin \
    xorriso \
    squashfs-tools \
    libncurses-dev


Additional tools:

🔧 x86_64 ELF cross-compiler.
🐧 GNU/Linux development environment.
🖥️ QEMU for virtualization.
📦 Git with submodule support.
🚀 Clone the Repository
bash
git clone --recurse-submodules \
https://github.com/Lebirun/Lebirun.git

cd Lebirun

🎛️ Configure

Launch the configuration environment:

bash
./lebconfig.sh


Configure the available project options using the interactive interface.

⚙️ Build

Initiate the build process:

bash
./build.sh

🖥️ Launch

Start the QEMU environment:

bash
./qemu.sh
